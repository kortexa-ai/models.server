# Archived Benchmarks

These files predate the reproducible benchmark workflow introduced on
2026-08-20. Keep them for historical context only.

- `BENCHMARKS-2026-08-20.md` contains results whose live process environment,
  power cap, graph state, or exact configuration was not always recorded.
- The legacy Qwen scripts directly manipulated services and launched servers.
  Do not use them for the new benchmark series.

No archived throughput number is a post-reset baseline.
