# kortexa.ai Nanbeige 4.1 3B LLM server

A simple service running Nanbeige 4.1 3B.

Nanbeige4.1-3B is a 3B parameter model from Nanbeige with 131K context support.

## Requirements

- macOS: MLX-LM (Apple Silicon)
- Linux: vLLM (CUDA recommended)

## Model

Using `Nanbeige/Nanbeige4.1-3B` via MLX-LM (macOS) or vLLM (Linux).
