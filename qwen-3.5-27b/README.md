# kortexa.ai Qwen 3.5 27B LLM server

A simple service running Qwen 3.5 27B (Q6_K quant).

Qwen3.5-27B is a 27B dense reasoning model from Qwen.

## Requirements

- 24GB+ VRAM recommended for Q6 quantization
- llama.cpp with llama-server

## Model

Using `unsloth/Qwen3.5-27B-GGUF` with Q6_K quantization.

## References

- https://huggingface.co/unsloth/Qwen3.5-27B-GGUF
